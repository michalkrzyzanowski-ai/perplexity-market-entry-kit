# Skill 00: Choose context mode

## Purpose

Select how company context will be supplied before any research starts.

## Ask the participant to choose

- **File-based:** usable company-context files are available.
- **Interview-based:** no usable company files are available.
- **Hybrid:** some files exist, but decision-critical information is missing.

## Instructions

1. Ask which mode the participant chooses.
2. Explain that files are preferred when available because they create traceable company evidence.
3. Explain that interview answers are participant-supplied internal inputs, not independently verified facts.
4. Record the choice and the available inputs in `decision/workflow-state.md`.

## Do not

- Do not research the web.
- Do not make a recommendation.
- Do not assume a file exists, is readable, is current, or contains the necessary facts.

## Output

Create or update `decision/workflow-state.md` with:

```md
# Workflow state

- Selected context mode:
- Decision topic:
- Available company files:
- Missing or unreadable files:
- Participant-supplied inputs:
- Current stage: context selection
- Research approval: not requested
- Human decision status: pending
```

## Human gate

The participant confirms the chosen mode and available inputs before context validation or interview begins.
